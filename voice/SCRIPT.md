# Narration script

Sixteen lines, in the order they appear. Recordings go in `voice/<lang>/` as
`01.m4a` … `16.m4a` (or `.mp3`), and are switched on with `voice` in
[`js/config.js`](../js/config.js). A missing file just means that line stays
caption-only. The story waits for each line to finish before moving on.
